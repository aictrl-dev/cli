# Security policy

## Report a vulnerability

Report suspected vulnerabilities in aictrl CLI through [GitHub private vulnerability reporting](https://github.com/aictrl-dev/cli/security/advisories/new). You can also open this repository's Security and quality tab and choose **Report a vulnerability**.

Please include:

- The affected CLI version and relevant operating system or runtime details.
- A minimal reproduction and the observed behavior.
- The potential security impact.
- Sanitized logs or examples that help reproduce the problem.

Do not post exploit details, credentials, tokens, or private data in public issues. Remove secrets and personal data from any logs or examples you share.

For ordinary bugs without a suspected security impact, use the [public issue tracker](https://github.com/aictrl-dev/cli/issues).
