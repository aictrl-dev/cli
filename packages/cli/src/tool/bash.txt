Runs a bash command for terminal operations such as git, package managers, builds and tests. Each call starts a new shell process.

Do not use it for file operations; use the dedicated tools instead: Glob (not find/ls), Grep (not grep/rg), Read (not cat/head/tail), Edit (not sed/awk/perl), Write (not echo/heredoc redirection).

All commands run in ${directory} by default. To run elsewhere, set `workdir` instead of using `cd`.

Commands time out after ${timeout}ms unless `timeout` (milliseconds) is set.

Output over ${maxLines} lines or ${maxBytes} bytes is truncated and the full output is written to a file; read it with Read (offset/limit) or search it with Grep. So do not limit output with `head`, `tail` or other truncation commands; run the command directly.

`description` is a short summary of what the command does.

Independent commands can run as separate parallel tool calls in one message; chain dependent commands with `&&`.
