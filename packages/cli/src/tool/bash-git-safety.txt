# Git safety
- NEVER commit, push or open pull requests unless the task explicitly asks for it
- NEVER skip hooks (--no-verify, --no-gpg-sign, etc). If a hook fails, fix the issue and create a NEW commit
- NEVER force push, amend commits or run destructive git commands (like reset --hard) unless explicitly asked
- NEVER update the git config
- Never use git commands with the -i flag, since interactive input is not supported
- Use the gh command for GitHub-related tasks (issues, pull requests, checks, releases)
